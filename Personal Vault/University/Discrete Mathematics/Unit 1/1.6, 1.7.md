###### How to prove universal / existentially quantified statement?
First note that if domain= {1, 2, 3}, then
• ∀ x, P (x) ≡ p(1) *^* p(2) *^* p(3)
• ∃ x, P (x) ≡ p(1) *v* p(2) *v* p(3)

|            | To Prove (T)                                | To Disprove (F)                              |
| ---------- | ------------------------------------------- | -------------------------------------------- |
| ∀ x, P (x) | Show it is true for every x in the domain   | Show one example x value where P(x) is false |
| ∃ x, P (x) | Show one example x value where P(x) is true | Show it is false for every x in the domain   |

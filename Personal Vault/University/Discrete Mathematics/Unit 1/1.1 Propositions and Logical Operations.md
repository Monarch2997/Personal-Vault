###### Converse, Contrapositive, Inverse
the converse of p->q is **q->p**
the contrapositive of p->q is **~q->~p**
the inverse of p->q is **~p->~q**

| p   | q   | ~p  | ~q  | p->q | **q->p** | **~q->~p** | **~p->~q** |
| --- | --- | --- | --- | ---- | -------- | ---------- | ---------- |
| T   | T   | F   | F   | T    | T        | T          | T          |
| T   | F   | F   | T   | F    | T        | F          | T          |
| F   | T   | T   | F   | T    | F        | T          | F          |
| F   | F   | T   | T   | T    | T        | T          | T          |

###### Ex. If i live in Boise, then I live in Idaho

**Converse:** if i live in Idaho, then I live in Boise
**Contrapositive:** If i don't live in Idaho, then I don't live in Boise
**Inverse:** If i  don't live in Boise, then don't I live in Idaho

###### If x >= 0, then x^2 >= 0
**Converse:** If x^2 >= 0, then x >= 0
**Contrapositive:** If x^2 < 0, then x < 0
**Inverse:** x < 0, then x^2 < 0

###### ex. (~p) *v* q
p: it is windy
q: it is cold
r: it is raining
= it is not windy or it is cold

compare this to ~(p *v* q)
= it is not windy or cold

###### ex pt2. Write "it is raining and windy or it is cold"

###### How many rows does a truth table have?
1 variable = 2 rows
2 variables = 4 rows
3 variables = 8 rows
4 variables = 16 rows
n variables = n^2 rows

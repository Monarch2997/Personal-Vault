- A proof by cases of a universal statement such as “∀x, P(x)”, or “If x is an integer, then...” breaks the domain for the variable into different classes and gives a different proof for each class. 
- Every value in the domain must be included in at least one class.

## Example 1: If n is an integer, then n^2 + n is even
*Case 1:* Let n be an **even** integer
since n is even, **n=2k** for some integer k
then n^2 + n = (2k)^2 + 2k = 4k^2 + 2k = 2(2k^2 + k)
since **2, k** are integers, **2k^2 + k** is also an integer
Hence,  if n is an even integer, then n^2 + n is even

*Case 2:* Let n be an **odd** integer
since n is odd, **n=2k+1** for some integer k
since n^2 + n = (2k+1)^2 + 2k + 1 = 4k^2 + 6k + 2 = 2(2k^2 + 3k + 1)
since **1,2,3, k** are integers, **2k^2 + 3k +1** is also an integer
Hence, n^2 + n  = 2(2k^2 +3k +1), which is even
